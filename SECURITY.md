# Güvenlik politikası

## Desteklenen sürümler

Güvenlik düzeltmeleri projenin en son `main` sürümüne uygulanır.

## Güvenlik açığı bildirimi

Bir güvenlik açığının ayrıntılarını herkese açık issue olarak paylaşmayın. GitHub deposundaki **Security → Report a vulnerability** seçeneğini kullanın. Özel bildirim kullanılamıyorsa hassas ayrıntı içermeyen bir issue açarak proje sahibinden özel iletişim kanalı isteyin.

Raporda etkilenen sürümü, tekrar üretme adımlarını, olası etkiyi ve varsa düzeltme önerisini belirtin. Gizli bilgi, kişisel veri veya imzalama anahtarı eklemeyin.
